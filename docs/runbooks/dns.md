# DNS runbook
Per domain (generate via UI `/api/v1/domains/{id}/dns`):
- `mail.example.com A <server IP>`
- `example.com MX 10 mail.example.com`
- SPF: `v=spf1 a:mail.example.com -all`
- DKIM: `<selector>._domainkey TXT v=DKIM1;...` (generated by synth-dkim)
- DMARC: `v=DMARC1; p=none; rua=mailto:dmarc@example.com` (start none → quarantine → reject)
- PTR: `<IP> → mail.example.com`
- MTA-STS + TLS-RPT + DANE as in Plan §10.
